# Hotel Booking & Management System

A full-stack hotel booking and management web application developed as an individual academic project.

## Features
- Hotel browsing and booking
- Room management
- Booking management
- User-facing booking interface
- Hotel management functionality
- PayPal payment integration

## Technology
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Local Setup
1. Install XAMPP or another PHP/MySQL environment.
2. Create a local MySQL database.
3. Import the project's database schema if provided separately.
4. Copy `connection.example.php` to `connection.php`.
5. Add your local database credentials to `connection.php`.
6. Run the project through your local PHP server.

## Security
Local database credentials and environment-specific configuration are intentionally excluded from this repository.
